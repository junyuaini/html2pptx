# H5 转 PPT 完整教程

## 一、目的：这个项目能解决什么问题

很多人直接让 AI 生成 PPT 时，经常会遇到样式不稳定、后续不好调整、内容不方便编辑等问题。

这个项目的核心思路是：先让 AI 按规则生成适合转 PPT 的 H5，再用 `html2pptx` 工具把 H5 转成可编辑 PPT。

如果你平时已经在使用 AI Agent 工具，建议直接用这类工具来操作这个项目。这里说的 AI Agent 工具包括 AI Coding 工具，也包括 Claude 等各种可以读取文件、修改文件、执行命令的 Agent 产品。它可以帮你读取目录、生成 H5 文件、修改页面代码、执行转换命令，比手动复制粘贴更方便。

这样做可以达到几个效果：

- 先在浏览器里预览 H5，效果不满意可以继续改
- 可以用自然语言让 AI 一页一页微调
- 转换出来的 PPT 与 H5 效果接近
- PPT 打开后可以继续编辑文字、图片、色块和版式
- 整个流程可控，有问题可以回到 H5 阶段修改，再重新转换

最终流程是：

```text
准备 PPT 内容 + H5 提示词
→ AI 生成 H5 设计文档
→ 确认设计文档
→ AI 生成 H5
→ 预览并微调 H5
→ 执行命令转换 PPT
→ 打开 PPT 继续微调
```

## 二、操作教程：四步完成 H5 转 PPT

### 如果你使用 AI Agent 工具，建议这样操作

现在很多人会用 AI Agent 工具来处理项目文件，比如让 AI 帮你读目录、改文件、生成内容、跑命令。它不一定非得是编程工具，也可以是 Claude 等各种 Agent 产品。这个流程很适合用这类工具来做。

如果你用 AI Agent 工具，可以按下面的方式操作：

1. 先把 `html2pptx` 项目下载到本地并打开。
2. 让 AI 先阅读 `教程/03-教程说明.md` 和 `教程/04-H5提示词.md`。
3. 把你自己准备的 PPT 内容放到 `教程/05-PPT内容（唯一自备）.pdf`，或者告诉 AI 你的内容文件在哪里。
4. 让 AI 基于 PPT 内容和 H5 提示词，先生成一份 H5 设计文档。
5. 确认设计文档没问题后，让 AI 把 H5 页面生成到 `教程/01-H5（AI生成）/` 目录。
6. 预览 H5，如果不满意，直接用自然语言让 AI 修改对应页面。
7. H5 确认没问题后，让 AI 在项目根目录执行转换命令，生成 PPT。

可以直接把下面这段话发给 AI Agent 工具：

```text
请先阅读 教程/03-教程说明.md 和 教程/04-H5提示词.md。
我的 PPT 内容在 教程/05-PPT内容（唯一自备）.pdf。
请先基于 PPT 内容和 H5 提示词生成 H5 设计文档。
我确认设计文档后，再把 H5 页面生成到 教程/01-H5（AI生成）/ 目录。
生成后请告诉我如何预览，并在我确认后执行转换命令生成 PPT。
```

如果你不会代码，也没有关系。你只需要告诉 AI 哪一页哪里不满意，比如“第 3 页太挤了”“第 5 页换成中国风配色”“第 7 页改成左右布局”，让 AI 去改文件即可。

### 第一步：准备 PPT 内容和 H5 提示词

开始之前，需要准备两份材料。

#### 1. 准备 PPT 内容

先准备一份你想做成 PPT 的内容。内容格式不限，可以是口述文字、Word、PDF、Markdown、大纲，或者任何已经整理好的资料。

内容越详细，AI 生成出来的 PPT 页面也会越详细；内容越简单，AI 会做更多创作和加工。

建议内容里至少包含：

- PPT 主题
- 目标受众
- 大概页数
- 每页想表达的重点
- 希望呈现的风格
- 是否需要图表、流程图、对比页、总结页等

示例材料在当前教程目录里：

```text
05-PPT内容（唯一自备）.pdf
```

也可以参考已经生成好的设计文档：

```text
06-H5设计文档（AI生成）.md
```

#### 2. 找到 H5 提示词

H5 提示词文件在当前教程目录里：

```text
04-H5提示词.md
```

这个提示词的作用是告诉 AI：

- 页面尺寸应该是多少
- 每一页 H5 应该怎么写
- 哪些布局适合转换成 PPT
- 字体、颜色、间距、卡片、图标等样式要遵循什么规则
- 哪些 CSS 或复杂效果不建议使用
- 如何保证后续转换成 PPT 时更稳定

#### 3. 把两份材料发给 AI

把“PPT 内容”和“H5 提示词”一起发给 AI。

建议不要一上来就让 AI 直接写 H5 代码，而是先让 AI 生成一份设计文档。

可以使用下面这段提示词：

```text
请帮我按生成一份H5版本PPT的设计文档
内容参考：05-PPT内容（唯一自备）.pdf
设计必须符合：04-H5提示词.md
输出：md文件
```

### 第二步：确认设计文档，让 AI 生成 H5

AI 会先生成一份 H5 设计文档。

拿到文档后，先简单检查：

- 页数是否符合预期
- 每页内容是否合理
- 页面顺序是否顺畅
- 风格是否符合主题
- 排版是否适合做 PPT
- 有没有明显缺页、重复页或内容跑偏

如果有问题，直接让 AI 修改设计文档。

例如：

```text
第 3 页和第 4 页内容有点重复，请合并一下。
整体页数控制在 10 页以内。
风格不要太花哨，偏简洁商务一点。
```

或者：

```text
第 5 页我希望重点讲具体操作方法，不要只写概念。
请把第 5 页拆成三个步骤，每个步骤配一个小标题。
```

确认设计文档没问题后，再让 AI 基于设计文档生成 H5。

可以这样说：

```text
这份设计文档没问题。请你严格按照这份设计文档和前面提供的 H5 生成规则，生成完整 H5 文件。
```

AI 生成 H5 后，把生成的 HTML 文件保存下来。

示例 H5 已经放在当前教程目录里：

```text
01-H5（AI生成）/page01.html
01-H5（AI生成）/page02.html
01-H5（AI生成）/page03.html
01-H5（AI生成）/page04.html
01-H5（AI生成）/page05.html
01-H5（AI生成）/page06.html
01-H5（AI生成）/page07.html
01-H5（AI生成）/page08.html
01-H5（AI生成）/page09.html
01-H5（AI生成）/page10.html
```

### 第三步：预览 H5，并用自然语言持续微调

H5 生成后，先在浏览器里打开看一遍。

如果使用教程里的示例文件，可以直接打开：

```text
01-H5（AI生成）/page01.html
```

然后按顺序查看 `page01.html` 到 `page10.html`。

重点检查：

- 整体风格是否符合预期
- 标题是否清楚
- 字号是否合适
- 每页内容是否太满
- 页面留白是否舒服
- 配色是否统一
- 重点信息是否突出
- 页面之间风格是否一致

如果有问题，不需要自己改代码，直接继续让 AI 修改。

例如：

```text
整体颜色我想换成中国风一点，主色用深红和米白，减少现在的蓝色。
```

```text
第 3 页内容太挤了，请把文字减少一点，并且把三个要点改成卡片布局。
```

```text
第 6 页的标题不够突出，请把标题字号加大，并增加一个强调色块。
```

```text
第 8 页我希望左右分栏，左边放问题，右边放解决方法。
```

建议这个环节尽量使用语音输入，因为语音可以说得更细。

如果你不懂技术，就直接描述你看到的问题：

```text
第 4 页中间那一块太靠下了，整体往上挪一点。
```

```text
第 7 页右边那三个小框看起来太挤，间距拉开一点。
```

如果你懂一点技术，也可以给 AI 更具体的要求：

```text
第 2 页标题区域高度控制在 180px 左右，正文卡片使用三列布局，卡片之间间距 24px。
```

推荐的修改方式：

- 优先一页一页改
- 每次只改一类问题
- 修改后继续预览
- 直到 H5 效果基本符合要求

H5 基本上可以改得比较细，只要描述清楚，AI 通常能按要求调整。

### 第四步：执行命令生成 PPT

H5 调整满意后，进入 `html2pptx` 项目根目录执行转换命令。

当前教程目录已经放在项目根目录下，所以目录关系是：

```text
html2pptx/
├── src/
├── package.json
└── 教程/
    ├── 01-H5（AI生成）/
    ├── 02-截图/
    ├── 03-教程说明.md
    ├── 04-H5提示词.md
    ├── 05-PPT内容（唯一自备）.pdf
    ├── 06-H5设计文档（AI生成）.md
    └── 07-转换结果示例.pptx
```

#### 1. 准备运行环境

这个项目需要先安装 Node.js，并且 Node.js 版本需要不低于 18。

可以先检查本机 Node.js 版本：

```bash
node -v
```

如果能看到类似 `v18.x.x`、`v20.x.x` 或更高版本，就可以继续。

#### 2. 进入 html2pptx 项目目录

如果你已经在项目根目录，可以跳过这一步。

如果你在项目上一级目录，可以执行：

```bash
cd html2pptx
```

#### 3. 安装依赖

第一次使用需要安装依赖：

```bash
npm install
```

安装时会自动安装转换 PPT 需要的依赖，包括 Puppeteer、pptxgenjs 等。

如果安装时间比较长，属于正常情况，因为 Puppeteer 可能会下载浏览器运行环境。

#### 4. 执行转换命令

项目的命令入口是：

```bash
node src/cli.js
```

命令格式是：

```bash
node src/cli.js 输入HTML文件或目录 -o 输出PPT文件路径
```

常用方式有三种。

##### 方式一：转换单个 HTML 文件

如果 AI 只生成了一个 `index.html`，可以执行：

```bash
node src/cli.js 教程/01-H5（AI生成）/index.html -o 教程/07-转换结果示例.pptx --verbose
```

这里需要替换两个位置：

- `教程/01-H5（AI生成）/index.html`：你的 H5 文件路径
- `教程/07-转换结果示例.pptx`：你想输出的 PPT 文件路径和文件名

##### 方式二：转换多个 HTML 文件

如果 AI 生成的是多页 HTML，比如 `page01.html` 到 `page10.html`，可以把多个文件依次写在命令里：

```bash
node src/cli.js 教程/01-H5（AI生成）/page01.html 教程/01-H5（AI生成）/page02.html 教程/01-H5（AI生成）/page03.html 教程/01-H5（AI生成）/page04.html 教程/01-H5（AI生成）/page05.html 教程/01-H5（AI生成）/page06.html 教程/01-H5（AI生成）/page07.html 教程/01-H5（AI生成）/page08.html 教程/01-H5（AI生成）/page09.html 教程/01-H5（AI生成）/page10.html -o 教程/07-转换结果示例.pptx --verbose
```

这种方式适合明确指定页面顺序，转换后的 PPT 会按照命令里的 HTML 顺序生成。

##### 方式三：转换整个目录

如果所有 HTML 都放在同一个目录里，也可以直接指定目录：

```bash
node src/cli.js 教程/01-H5（AI生成）/ -o 教程/07-转换结果示例.pptx --verbose
```

这种方式最简单，适合页面文件已经按 `page01.html`、`page02.html`、`page03.html` 这种顺序命名的情况。

#### 5. 查看转换结果

命令执行成功后，终端会出现类似提示：

```text
✅ PPT 已生成: 输出文件路径
```

然后打开输出的 `.pptx` 文件：

```text
教程/07-转换结果示例.pptx
```

重点检查三件事：

- 版式是否接近 H5
- 文字是否可以选中编辑
- 元素是否可以继续调整

如果效果不满意，不需要从头开始做。回到第三步，继续微调 H5，然后重新执行转换命令即可。

#### 6. 推荐给用户的简化命令

如果你直接使用当前教程里的示例 H5，可以主要记住这一条命令：

```bash
node src/cli.js 教程/01-H5（AI生成）/ -o 教程/07-转换结果示例.pptx --verbose
```
