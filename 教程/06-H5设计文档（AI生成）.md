## 一、整体设计风格规范

### 1.1 设计主题

**主题定位**：中国风心理成长风

**适用场景**：个人成长课程、心理健康科普、时间管理培训、自我管理主题分享

**设计关键词**：故宫红、鎏金、宣纸米色、墨色、温润、克制、东方秩序感

### 1.2 视觉表达原则

- 用宣纸米色降低“拖延症”话题带来的焦虑感
- 用故宫红与鎏金色强化标题、行动按钮和关键路径
- 用卡片、步骤、流程图表达可执行方法
- 用小目标、倒计时、进度条等视觉符号强化“立即行动”
- 避免过度华丽的纹样堆叠，整体基调保持温润、克制、易读
- 每页只聚焦一个核心观点，避免信息拥挤

## 四、统一 H5 生成约束清单

### 4.1 页面尺寸与结构

- 所有页面固定 `width: 1280px; height: 720px;`
- 禁止页面滚动，所有内容必须在 1280×720 范围内完整可见
- 内容页统一使用 `page-header + page-body + page-footer`
- `page-header` 高度 80px，`page-body` 高度 590px，`page-footer` 高度 50px

### 4.2 技术限制

- 禁止 JavaScript
- 禁止外部 CSS 框架
- 禁止动画和过渡效果
- 禁止 box-shadow
- 禁止 CSS 变量
- 禁止依赖网络字体
- 禁止使用本地相对路径图片

### 4.3 文本与装饰规范

- 普通正文允许自动换行
- 短标签、编号、页码、步骤标题必须设置 `white-space: nowrap`
- 列表圆点、勾选符号、编号徽章必须使用独立 DOM 元素
- 图标、编号、徽章需要居中时使用 flex 居中
- 关键视觉元素不要完全依赖 `::before` 或 `::after`

### 4.4 转换优化要求

- 所有文本明确设置 `font-size`、`color`、`font-family`
- 所有白色卡片明确设置 `background-color: #FFFFFF`
- 圆角统一使用 `border-radius`
- 阴影层次用边框、浅色背景或装饰线表达
- 渐变只使用 `linear-gradient()`
