快速上手使用

3步完成HTML到PPT转换

即装即用 CLI工具 批量支持
安装步骤
1
进入项目目录 cd html2pptx
2
安装依赖 npm install
3
开始使用 node src/cli.js
< 使用示例 >
示例1
node src/cli.js test/cover.html -o output.pptx
示例2
node src/cli.js slide1.html slide2.html -o output.pptx
示例3
node src/cli.js ./slides/ -o output.pptx --verbose
参数说明表格
inputs
HTML文件/目录路径
必填
-o, --output
输出.pptx文件路径
output.pptx
-s, --scale
px→pt缩放系数
0.75
-v, --verbose
显示详细日志
false
-V, --version
显示版本号
false
HTML输入规范
纯静态HTML+CSS（不含JavaScript）
页面尺寸固定1280×720px
字体使用白名单字体（微软雅黑等）
颜色使用纯色（十六进制或RGB）
图片使用绝对URL
